## 修复下载配额逻辑（按账号维度）

**问题**：同一网络下多台设备下载，IP 共享配额，导致已登录用户在多台设备上无法各自享受 3 次/天配额。

**根因**：`api/auth.js` 第 143 行：`const totalUsed = Math.max(ipUsed, userUsed);`
已登录用户的配额取 `IP 已用次数` 和 `账号已用次数` 的最大值，导致同一 IP 下所有设备共享配额。

**修复**：改为只看账号维度
```javascript
// 改前
const totalUsed = Math.max(ipUsed, userUsed);

// 改后  
const totalUsed = userUsed;
```

**影响**：
- ✅ Guest 用户不受影响，仍然是 `1次/IP/天`
- ✅ 已登录用户：同一账号在多台设备/IP 下共享 3 次/天配额
- ✅ IP 计数仍写入 Redis，保留作风控审计

**提交**：commit `0daf5c08`
