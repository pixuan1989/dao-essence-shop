## 什麼是八字命盤？

**八字命盤**（「八字」，字面意為「八個漢字」）是一份根據你出生「精確時刻」所繪製的個人化中國占星藍圖。它記錄了你降生那一刻天地間的能量分布，揭示你在性格、人際、事業、健康與整體人生走向上的潛在模式。

命盤由**四柱**構成——年柱、月柱、日柱與時柱；每柱皆由一個「天干」加一個「地支」組成，共計**八個漢字**。

> 「八字命盤並非宿命論工具。它展現的是傾向與潛能——就像你人生的氣象預報。最終如何應對，仍由你自己選擇。」——傳統八字教學箴言

## 四柱詳解

### 1. 年柱（年柱）
代表你的**祖上背景、社會環境與早年生活**。反映你出生所處的宏觀脈絡——例如家族社會地位、社區氛圍，以及你所屬世代的集體能量特質。

### 2. 月柱（月柱）
揭示你的**事業潛力、父母影響力，以及出生季節的主導能量**。此柱被視為四柱中最關鍵的一柱之一，因為它直接決定日主是否「得令」（身強）或「失令」（身弱）。

### 3. 日柱（日柱）
這就是**真正的你**。「日主」（日主）——即日柱的天干——代表你的核心自我、根本性格，以及你與世界互動的基本方式；而日柱的地支，則與你的**配偶、親密關係**密切相關。

### 4. 時柱（時柱）
反映你的**子女、內在渴望、晚年運勢與潛意識驅力**。它展現你深藏心底的志向，以及你希望留給世界的遺產與影響。

## 如何判斷日主強弱？

解讀八字最關鍵的第一步，就是確認你的**日主屬於身強或身弱**。這將直接決定你的「用神」——也就是你命中最需要、最能助益你的五行元素。

### 步驟一：確認日主所屬五行  
查看你日柱的天干，每一種天干皆對應五行之一：

|---|---|---|
| 甲（甲） | 木 | 陽 |
| 乙（乙） | 木 | 陰 |
| 丙（丙） | 火 | 陽 |
| 丁（丁） | 火 | 陰 |
| 戊（戊） | 土 | 陽 |
| 己（己） | 土 | 陰 |
| 庚（庚） | 金 | 陽 |
| 辛（辛） | 金 | 陰 |
| 壬（壬） | 水 | 陽 |
| 癸（癸） | 水 | 陰 |

### 步驟二：檢視出生季節（得令與否）  
你的日主是否誕生於其「當令」的季節？  

- **木**：春季（寅、卯、辰月）最旺  
- **火**：夏季（巳、午、未月）最旺  
- **土**：四季之交（辰、戌、丑、未月）皆得令  
- **金**：秋季（申、酉、戌月）最旺  
- **水**：冬季（亥、子、丑月）最旺  

### 步驟三：計算支援元素數量  
統計命盤中其他天干與地支，有多少與日主同五行，或透過「相生」關係（如木生火、火生土等）滋養日主。

- **身強**＝出生於當令季節 ＋ 命中支援元素多  
- **身弱**＝出生於失令季節 ＋ 命中支援元素少  

## 十神（十神）關係解析

一旦確認日主，即可推算命盤中所有其他干支與日主之間的「十神」關係——這是理解性格、行為模式與人生課題的核心鑰匙：

- **與日主同五行者**：比肩（比肩）或劫財（劫財）  
- **日主所生者**：食神（食神）或傷官（傷官）  
- **日主所剋者**：正財（正財）或偏財（偏財）  
- **剋制日主者**：正官（正官）或七殺（七殺）  
- **生助日主者**：正印（正印）或偏印（偏印）

## 值得留意的常見格局

### 🐉 時支見「辰」（龍）  
若你的時柱地支為「辰」，往往顯示你天生具備領導才能與轉化變革的潛質。

### 🔥 三柱皆為「火」  
命盤中火氣過旺，常代表熱情洋溢、感染力強的性格——但須留意情緒耗竭或身心過度燃燒的風險。

### 💧 水克火過重  
若命局中水勢壓倒火勢，你可能較難自然表達情感；此時你的用神很可能是**木**（木可洩水生火，成為水與火之間的橋樑）。

### ⚔️ 地支相沖（沖）  
當命盤中有兩地支形成「相沖」（例如子午相沖），往往暗示該領域（如事業、感情、健康）易出現重大轉折，或內在存在明顯拉扯與衝突。
